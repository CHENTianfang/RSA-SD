# The Model and Experimental Study of Rational Speech Acts under Semantic Deviation

This repository contains the experimental and analysis code for the paper **"The Model and Experimental Study of Rational Speech Acts under Semantic Deviation."**

## Repository Structure

```
.
├── jsPsych/                # Experimental programs developed using jsPsych
├── analysis/               # Data analysis
├── README.md
└── LICENSE.txt
```

### 1. `jsPsych/`
This directory contains the experimental programs developed using [jsPsych](https://www.jspsych.org/), a JavaScript framework for running behavioral experiments in web browsers.
- **Purpose:** The experiments simulate various Rational Speech Act (RSA) scenarios under semantic deviation.
- **Instructions:** You can run the experiments locally or deploy them online by following the standard jsPsych setup.

### 2. `analysis/`
This directory contains Python scripts for analyzing the experimental data.
- **Purpose:** Perform statistical analysis to explore how semantic deviation impacts RSA-based communication strategies.
- **Details:** The analysis code includes data preprocessing and statistical tests.
